## 标注规则

银标已经写入以下列：

- `label`：当前银标，取值为 `A`、`B` 或 `C`
- `label_note`：银标依据，并明确标记为 `silver/AI-assisted`
- `silver_score`：可复现的辅助分，不是线上排序分
- `silver_confidence`：银标置信度

人工复核只填写复核文件中的：

- `human_label`：`A`、`B` 或 `C`
- `human_note`：简短说明人工判断依据

| 标签 | 含义 |
|---|---|
| `A` | 当天必须优先阅读，应该进入速览前 5 |
| `B` | 值得阅读，但不应优先于大多数 A 类事件 |
| `C` | 可低优先级展示、隐藏，或不应进入重点速览 |

判断时优先考虑：

1. 事件本身的重要性和影响范围；
2. 是否有明确的新事实或新进展；
3. 信息是否可靠、具体、可验证；
4. 是否只是同一消息的重复转载；
5. 是否属于个人偏好而非公共重点。

不要因为当前 `rank` 很高就直接标 A；评测集的目的就是检查当前排序是否正确。

## 建议标注顺序

优先标注：

1. 每个日期/频道的 Top 5；
2. `rank` 与 `rank_score` 接近但内容差异明显的候选；
3. 单源高质量内容；
4. 多源但疑似转载的内容；
5. 历史 `item_count` 较高、但当天新增较少的事件；
6. 同一事件出现在多个频道的样本。

### 可用于诊断的案例

- 最高法网络转载许可：银标 B → 人工 A，当前排名 8。
- 达摩院肝癌 AI 模型：银标 C → 人工 A，当前排名 20。
- OpenAI 推理芯片单条：银标 C → 人工 A，当前排名 4。**银标误判不等于排序误判**，该条当前已经在 Top 5。
- 小鹏机器人融资：3 个日期均为银标 A → 人工 B；不能因重复采样把它当作 3 个独立事件的证据。
- 包管理器周报、OpenAI/Hugging Face 教训：在观点实践频道均为银标 B → 人工 A。不能把“周刊/观点/教程”这些形式一律作为低价值信号。

以上为标签差异事实，不代表已经确认误差成因；没有人工备注时，不应自动推断主题偏好。

### 评测限制与后续使用

1. 这批是单人复核的诊断集，**不是跨用户通用金标准，也不直接进入个人画像**。
2. 60 条覆盖 11 个日期、55 个不同 entry；其中 56 条集中于 08-24～08-30。抽样偏向早期、边界及冲突，不能外推至整月。
3. 794 条本身是抽样候选，不是完整候选池；不支持任意新版排序的完整离线重放。正式回放需要冻结完整候选特征及算法版本。
4. 只有 08-24 的三个频道具有完整的人工 Top 5 标签：重点事件 A/B/C=1/3/1，观点实践=0/0/5，产品资源=0/1/4。其他日期不完整；不报告整月 Precision@5/10 或 nDCG。把未标注项当 C 或把银标补成人工标签都会污染指标。
5. 生产快照反映导出时状态，不保证历史日的内容与聚类状态；例如 08-24 样本存在 08-26 的 latest_created_at。它只能作为回溯诊断，不是严格的历史时点回测。
6. 当前银标实际上由确定性关键词/特征规则生成，并非模型逐条语义阅读；其 `silver_confidence` 只是到阈值的距离，不是校准概率。不能用它自证通用排序。
7. 先拆分通用排序与个人偏好，再验证事件重要性、频道相关性及来源独立性。不要据这 60 条直接调整公共权重，也不要一律提升 AI 或降低融资内容。
8. 目前不需要重标这 60 条。下一轮如需正式比较排序，先按月份/频道均衡抽样并补齐选定日期的候选标签；最好隐藏当前排名与银标，减少锚定偏差。本文保留用户原标签，不自动扩散到相同 entry 的其他日期。

## 评测边界

该评测集只评估“值得优先阅读”的编辑排序，不评估：

- 外部平台热度；
- 用户点击率；
- 个性化偏好；
- 聚类合并正确性。
